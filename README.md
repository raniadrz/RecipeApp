# Οι Συνταγές μου 🍲

Εφαρμογή Android (Kotlin + Jetpack Compose) για να κρατάς τις συνταγές σου, να φτιάχνεις λίστα αγορών
και εβδομαδιαίο πρόγραμμα γευμάτων. Όλα στα ελληνικά, **χωρίς internet** — τα δεδομένα μένουν στο κινητό.

## Εγκατάσταση
Κατέβασε το [`apk/OiSyntagesMou-1.0.apk`](apk/OiSyntagesMou-1.0.apk) στο κινητό, άνοιξέ το και επίτρεψε
«Εγκατάσταση από άγνωστες πηγές». Απαιτεί Android 8.0 ή νεότερο.

## Λειτουργίες
**Συνταγές**
- Τίτλος, κατηγορία, υλικά (ποσότητα, μονάδα, τμήμα σούπερ μάρκετ) και βήματα εκτέλεσης
- Φωτογραφία από κάμερα ή συλλογή (μικραίνει αυτόματα και διορθώνεται ο προσανατολισμός)
- Χρόνος προετοιμασίας/μαγειρέματος, μερίδες, δυσκολία (εύκολη/μέτρια/δύσκολη)
- Ετικέτες: Νηστίσιμο, Χορτοφαγικό, Χωρίς γλουτένη, Παιδικό, Γρήγορο
- Αγαπημένα, αναζήτηση (χωρίς να μετράνε οι τόνοι), φίλτρα κατηγορίας/ετικέτας/δυσκολίας
- «Τι φτιάχνω με…»: ψάχνει και στα υλικά· με κόμμα (`κοτόπουλο, πατάτες`) βρίσκει συνταγές με όλα τα υλικά
- Γρήγορη επικόλληση υλικών/βημάτων (π.χ. «500 γρ. κιμάς» αναγνωρίζεται αυτόματα)
- Αλλαγή μερίδων με αυτόματο υπολογισμό ποσοτήτων
- Βαθμολογία με αστεράκια και σημειώσεις
- Λειτουργία μαγειρέματος: η οθόνη μένει ανοιχτή, ένα βήμα τη φορά, χρονόμετρο με ήχο/δόνηση
  και αυτόματη πρόταση χρόνου από το κείμενο του βήματος («ψήσε για 40 λεπτά» → 40')
- Αποστολή συνταγής σε φίλο (κείμενο + φωτογραφία) μέσω Viber, WhatsApp, SMS ή άλλης εφαρμογής

**Λίστα αγορών**
- Τα ίδια υλικά ενώνονται: «2 κρεμμύδια» + «1 κρεμμύδι» = «3 κρεμμύδια» (και γρ.+κιλά, ml+λίτρα)
- Ομαδοποίηση ανά τμήμα σούπερ μάρκετ (μαντεύεται αυτόματα, αλλάζει με ένα πάτημα)
- Τσεκάρισμα, προσθήκη δικών σου ειδών, επεξεργασία/διαγραφή
- Αποστολή σε Viber, WhatsApp ή SMS

**Επιπλέον**
- Εβδομαδιαίο πρόγραμμα (πρωινό/μεσημεριανό/βραδινό) που φτιάχνει τη λίστα αγορών της εβδομάδας
- Αντίγραφο ασφαλείας: εξαγωγή/εισαγωγή αρχείου `.zip` (συνταγές, φωτογραφίες, λίστα, πρόγραμμα)
- Προσαρμόζεται σε κινητά και **foldable**/tablet: πλαϊνή μπάρα, λίστα + λεπτομέρειες δίπλα-δίπλα,
  δύο στήλες σε επεξεργασία και μαγείρεμα

## Build
```
./gradlew assembleRelease      # → app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest    # unit tests
```
Το release APK υπογράφεται με το debug κλειδί ώστε να εγκαθίσταται απευθείας. Για Google Play βάλε δικό σου κλειδί
στο `app/build.gradle.kts`.

## Δομή
- `data/` — Room βάση (συνταγές, υλικά, λίστα αγορών, πρόγραμμα), repository, backup
- `domain/` — κατηγορίες, μονάδες, τμήματα σούπερ μάρκετ, ανάλυση υλικών, κανονικοποίηση ελληνικού κειμένου
- `ui/` — οθόνες Compose (recipes, cooking, shopping, plan, settings)
